# Biblioteca de estilos de @jheitrujillob

Estilos guardados con la skill y el perfil de la cuenta de Jhei. No forman parte de la skill: el ZIP de `dist/` no los incluye.

| Estilo | Qué es |
|---|---|
| `estilos/frases-tipo-tweet` | Frase tipo tweet sobre foto. Incluye la serie "Si yo tuviera un/a…" con 10 negocios |
| `estilos/notas-a-mano-rojas` | Notas escritas a mano en rojo |
| `estilos/cuaderno-mapas-mentales` | Mapas mentales en hoja de cuaderno |
| `estilos/tutorial-paso-a-paso-ui` | Tutorial paso a paso con capturas de interfaz |

`estilos/catalogo_estilos.png` es el catálogo visual.

## Usarla en una sesión nueva

```bash
mkdir -p /home/user/carruseles
cp -r biblioteca/estilos /home/user/carruseles/
cp biblioteca/perfil-jheitrujillob.json /home/user/carruseles/perfil.json
```
